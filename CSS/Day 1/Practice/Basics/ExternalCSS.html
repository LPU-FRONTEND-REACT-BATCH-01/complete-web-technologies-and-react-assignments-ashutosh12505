Inline CSS has the highest priority. Among internal and external, whatever (style or link) is written later in head tag is applied.

Types of selectors

  • Simple Selector
  • Combinator Selector
  • Pseudo Selector

Simple Selectors

  • Id (#)
  • Class (.)
  • Universal (*)
  • Tagname (p, a, h etc)
  • Grouping (,) example: h1, p, a{}

Selectors Priority

  1. ID Selector
  2. Class Selector
  3. Element Selector

Combinator Selectors

  • Descendent Selector (Parent-Child hierarchy, all Child inside Parent) (Parent Child)
  • Child Selector (Parent-Child hierarchy, only direct Child inside Parent) (Parent>Child)
  • General Sibling Selector (Same level, not nested) (Element~All_Siblings)
  • Adjacent Sibling Selector (Same level, only adjacent element) (Element+Adjacent)

Pseudo Selectors

    Pseudo-Classes

  • Visited (already visited)
  • Active (on clicking and dragging)
  • Link (not visited)
  • Hover
  • Focus

  • First-of-type ::
